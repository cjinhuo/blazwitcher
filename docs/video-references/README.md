# 视频产品界面参考

这四张图片来自用户为首页视频提供的截图，保留原始像素：

- `search-results.png`：拼音搜索、结果高亮、标签与历史分组。
- `command-menu.png`：`/s`、`/ai`、`/t`、`/h`、`/b` 命令菜单。

截图包含旧版 `v1.0.0` 窗口标题。Remotion 的视频图层将标题统一为 `Blazwitcher`，并叠加输入演示、轻微推近和重点提示；这些图层不改写原始图片。画面用于展示产品交互与视觉，不用于声明当前运行版本。
